## Project Overview

**Concrete Rose Graphics** is a creative business offering graphic design, web development, and digital experiences. This project presents its online portfolio, services, and business identity through a responsive website designed to be welcoming, clear, and easy to explore.

This repository is part of **Tanesha Berry's** professional portfolio, showcasing the intersection of frontend development and graphic design.

## Project Goals

- Create a consistent digital home for the Concrete Rose Graphics brand.
- Present services and selected work with a clear visual hierarchy.
- Help prospective clients understand offerings and find ways to connect.
- Support a responsive experience across desktop and mobile screens.
- Balance expressive brand design with usability and accessibility.

## Technology

- **Frontend:** React, JavaScript, Vite
- **Styling:** Tailwind CSS, responsive layouts
- **Platform / tooling:** Base44
- **Design:** Interface design, branding, graphic design
